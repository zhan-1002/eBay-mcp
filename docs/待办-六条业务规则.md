  `infer_pack_factors()`（按价格倍数猜件数）整段注释；

  仅保留 `DatasheetRow`（搜索回显）与 `Change`（漂移比对）。

作废的三条旧口径：

1. ~~最低售价 = 价格 + 运费，低于就抬到刚好等于最低售价~~
2. ~~价格只涨不降~~
