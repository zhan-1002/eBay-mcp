## 待改的具体位置

### 规则 2：修改日期默认留空

- 选择器：`soldeazy.py` 的 `SELECTORS["search_date"]` = `form select[name=listdate]`
- 现状：搜索时没有设置它，会沿用页面上次的值
- 做法：新增 `_clear_date_filter()`，把该 select 置空（找 value 为空/default 的选项），
  在 `search()` 里调用，位置与 `_select_status_listed()` 相邻
- 注意：找不到该下拉时跳过，不阻断搜索

### 规则 5：运费取分号前

- 位置：`soldeazy.py` 的 `_number(text)`
- 现状：`_number("0;8")` → `float("0;8")` 抛错 → 返回 `None`，该行运费丢失
- 做法：先按 `;` / `；` 切分取第一段再解析
- 影响面：`parse_rows` 里的 `postage`，以及 `price`（同样格式时一并容错）

### 规则 3：默认导出全部搜索结果

- 已有 `_select_scope_whole_result()`，`search()` 里已调用
- 需核实：导出弹层的范围选项是否也默认「全部结果」；
  若导出走 `export_via_api()`（`bulk_option=whole_result`），则已满足
