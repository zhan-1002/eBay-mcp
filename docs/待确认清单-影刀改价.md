### C2 打包行的「数量」是什么单位
- 结论（2026-11-02 确认）：**不做打包换算**。库存针对的是这个产品本身的件数，

### C6 单行数据表里的「打包型」SKU 怎么算
- 结论（2026-11-02 确认）：孤身行没有阶梯可比，用「最低售价 vs 现价」判：
  - **最低售价 < 现价** → 它是套装，件数 = round(现价 ÷ 最低售价)，
    目标 = 最低售价 × 件数；偏离整数超过容差则报「认不出」，不改价。
  - **最低售价 ≥ 现价** → 单件，直接抬到最低售价。
- 样例（最低售价 30.95）：
  - 第 12 行 `ZMHB0004US x4` 91.48 → 3 件装 → 92.85
  - 第 14 行 `ZMHB0004US x3` 80.49 → 3 件装 → 92.85
  - 第 13 行 `ZMHB0004US` 28.48 → 单件 → 30.95
- 注意：判断不依赖 SKU 上的 ` xN`，只用价格关系。
- 回归用例：`test_lone_row_above_minimum_is_treated_as_a_bundle`、
  `test_lone_row_below_minimum_stays_a_single_unit`、
  `test_lone_row_with_a_ratio_far_from_an_integer_is_left_alone`。
- 状态：已确认
