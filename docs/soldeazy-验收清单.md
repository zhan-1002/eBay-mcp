## A. 登录与会话（决定"会不会反复登录"）

### A1 cookie 跨进程恢复
- **目的**：确认重启进程后不必重新登录
- **步骤**：登录一次 → `close()` → 新进程启动 → 直接搜索
- **通过标准**：新进程 `interactive_login()` 返回 `reused_session=True`，且**未出现登录页**
- **失败处理**：检查 `session_cookies.json` 是否含 `_ht_ses_`；若会话 cookie 无法跨进程，改为"常驻进程"方案
- **产出**：一条日志记录（含 cookie 名字与过期时间）

### A2 无头模式首次登录
- **目的**：日常无窗口，但没会话时能自动登录
- **步骤**：删掉 `session_cookies.json` 与 profile 的 cookie → 无头启动
- **通过标准**：自动填入账号密码 + 勾「记住用户名」→ 登录成功；**全程无窗口弹出**
- **失败处理**：若站点有验证码/风控，降级为"首次有头登录、之后无头运行"
