## 三、为什么不能靠页面识别

实测：列表页筛选只有
`产品SKU / 渠道帐号 / 渠道站点 / 刊登方式 / 物品编号 / 标题 / 状态 / 数据表编号 / 上载文件名称 / 修改日期 / 排序方式`

- **没有"创建人"筛选、没有标签分组、没有精确到分钟的创建时间**
- 唯一带身份的字段是 `dsheet_filename = "superlaptop Download from <item_id>"`，但**同账号同事建的表前缀也一样**，无法区分"我建的"与"同事建的"
- 结论：**页面没有分组/标记能力，必须靠本地清单**
